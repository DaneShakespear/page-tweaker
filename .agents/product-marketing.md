# Product Marketing Context

**Document version:** v2
**Last updated:** 2026-09-09

## Product Overview

**One-liner:** AI PagePolish by PageTweaker is a visual feedback tool for AI-built websites.

**What it does:** Open any HTML file, local page, or live website. Try visual adjustments, draw and explain feedback, then drag one complete handoff into an AI chat.

**Product category:** Visual website feedback and AI handoff tool.

**Product type:** Free public macOS desktop app.

**Business model:** No paid plan established.

## Target Audience

**Primary users:** People building or revising websites and interfaces with AI coding agents, including non-designers, developers, founders, and designers.

**Primary use case:** Communicate the final visual 10% of an AI-built page without repeated vague prompting.

**Jobs to be done:**

- See a possible adjustment on the real page before committing to it.
- Explain visual intent without needing design or CSS terminology.
- Give an AI enough context to make the correct change in one pass.

## Problems and Pain Points

**Core problem:** People often know a page feels wrong but cannot describe the exact correction until they see it.

**Why alternatives fall short:** Text prompts force the AI to guess. Screenshots lose the exact element, tested adjustment, page, breakpoint, and explanation. Developer tools expose implementation details instead of helping users communicate the desired result.

**What it costs:** Repeated prompting, wasted tokens, slow revisions, and changes that still miss the intended outcome.

## Differentiation

- Opens local HTML, public URLs, and the current Chrome page without requiring an extension.
- Lets the user try visible changes without modifying the source.
- Combines adjustments, text, pinned notes, grouped drawings, page context, breakpoints, and annotated screenshots.
- Produces one draggable AI handoff that describes the outcome without prescribing the code architecture.

## Customer Language

**Problem language:**

- “Make it a little bigger.”
- “Not that big.”
- “Move it slightly left.”
- “Try a different gray.”
- “I know it feels wrong, but I do not know what I want until I see it.”

**Core promise:** Stop explaining. Show your AI.

**Supporting line:** Open it. Adjust it. Show AI.

**Words to use:** show, see, try, adjust, draw, explain, page, AI chat, complete brief, handoff.

**Words to avoid in the lead:** CSS editor, DOM, selectors, schema, evidence-rich, implementation architecture, visual QA, webview, Electron.

## Brand Voice

**Tone:** Direct, clear, confident, human.

**Style:** Short statements, familiar examples, plain language, and contrast between guessing and seeing.

**Personality:** Practical, visual, fast, precise, uncomplicated.

## Product Boundaries

AI PagePolish by PageTweaker does not edit source files, deploy websites, dictate implementation code, copy browser credentials, or replace the AI coding agent. It captures what the user wants so the agent can make the real change appropriately.

## Naming status

- External verification did not find a strong direct GitHub repository collision for `AI PagePolish`.
- `PagePolish` is already an active product family name (for example, RedKernel’s Confluence offering), so we should keep a transition anchor.
- Locked public brand: `AI PagePolish by PageTweaker`.
- Keep `PageTweaker` as legacy/contextual anchor in migration notes, repository references, and technical identifiers until a separate long-term rename decision.

## Goals

**Primary goal:** Make visitors understand the product and its value within seconds.

**Conversion action:** Download the latest macOS release.
