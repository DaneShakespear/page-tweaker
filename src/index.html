Drag a URL, artifact URL, HTML file, or Safari web link onto the app icon or anywhere in the window. You can also use Open With, paste a URL, or choose a file.

Try your feedback

Choose desktop, tablet, or mobile. Click an element and try sizes, spacing, colors, or replacement text without changing the real page.

3
Explain what you want

Pin a note to an element or draw a mark with its own explanation. Page Tweaker remembers which preview size each item belongs to.

4
Give the brief to your AI

A handoff is simply one file containing all your feedback and preview choices. Click Create handoff, then drag that file into your AI chat so the agent can make the real changes correctly.

Open from another app

Install Page Tweaker in Applications. It registers as a handler for public web links and HTML/web-link files, so apps with an “Open with” or browser picker can offer Page Tweaker. It never makes itself your default browser automatically.

Everything is preview-only. Your original file or website is never modified.
