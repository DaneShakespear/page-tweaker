# PageTweaker v0.1.16

PageTweaker is a visual feedback and AI-handoff workspace, not a CSS editor. Open a local page or website, try changes in context, explain what you want, mark up the page, and export one evidence-rich brief for your AI session.

## What is new

- Page-aware feedback across normal site navigation, with a browser Back button and separate edits, notes, markup, and screenshots for each URL and breakpoint.
- Grouped markup items: draw several circles, arrows, or lines under one explanation. Changing color naturally begins a new item.
- Live font-weight control, practical typography ranges, clearer changed-state indicators, and property-specific resets.
- A redesigned startup workspace with drag-and-drop opening, bare-domain URL support, file selection, and an illustrated draggable Chrome shortcut.
- Safer live formatted-text previews and clearer AI handoffs using schema version 6.
- A confirmed clear-page action and a more focused public explanation of what PageTweaker does and why.

## Install on macOS

This Apple Silicon release is ad-hoc signed for bundle integrity. It is not Developer ID signed or Apple notarized, so macOS may show a first-launch warning or block it initially.

Use the safe per-app steps in [Installing PageTweaker](https://github.com/DaneShakespear/page-tweaker/blob/main/docs/INSTALLING.md). Do not disable Gatekeeper globally.
