# Security policy

PageTweaker is designed to review local HTML files and public URLs without modifying the opened source or reusing browser authentication.

If you find a security issue, do not open a public issue with exploit details. Use GitHub's private vulnerability reporting for this repository when available, or contact the repository owner through GitHub first.

Please include the affected version, macOS version, clear reproduction steps, impact, and any proof-of-concept material needed to validate the report.
