Selecting links and login controls

Use links, buttons, and form fields normally. To select one for tweaking instead, hold ⌥ Option while clicking it.

Passwords and protected pages

PageTweaker keeps its own website sessions after you sign in, but it cannot use Chrome or Safari password-manager extensions. Use your password manager’s app or menu to copy and paste credentials. PageTweaker never stores them itself.

Open from another app

Install PageTweaker in Applications. It registers as a handler for public web links and HTML/web-link files, so apps with an “Open with” or browser picker can offer PageTweaker. It never makes itself your default browser automatically.

Everything is preview-only. Your original file or website is never modified.
